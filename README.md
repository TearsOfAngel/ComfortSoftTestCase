1. Клонировать проект
2. Запустить в IDE (IJ IDEA в идеале)
3. Сгенерировать Get запрос GET http://localhost:8080/api/min?filePath=file.xlsx&n=5
4. Убедиться в правильности ответа

В проекте лежит файл со значениями: 50 2 1 6 8 10 23
Для n = 5 ответ будет 10

Использован алгоритм QuickSelect. Рекурсивно перебирается список значений.
Выбирается опорный элемент. Все что меньше опорного переносится влево. Все что больше опорного вправо.
Если позиция опорного элемента становится равна k, то вот и ответ.
